## ⚡ Overview

**Waynex** is a next-generation, **Neuro-Symbolic Fleet Routing Platform** engineered to compute highly optimized multi-vehicle routes in **sub-50 milliseconds**.

Traditional mathematical solvers (like **Google OR-Tools** and MILP algorithms) scale exponentially in compute time ($O(e^N)$) as fleet sizes and delivery pin counts grow. Waynex solves this by pairing a **Spatial Graph Neural Network (GNN)** with a **Deep Reinforcement Learning (DRL) Actor-Critic Policy**, refined by a lightning-fast **2-Opt Symbolic Local Search**.

---

## 🧠 Architecture: The 3-Stage Neuro-Symbolic Pipeline

```
[ City Road Graph ]
        │
        ▼
[ 1. GNN Encoder ] ──► Spatial GAT + SAGEConv (64-dim Node Embeddings)
        │
        ▼
[ 2. DRL Policy ]  ──► Actor-Critic Advantage Policy + Action Masking (Sub-50ms Rollout)
        │
        ▼
[ 3. 2-Opt Search ] ──► Symbolic Local Search (Untangles Crossed Edges)
        │
        ▼
[ Optimized Fleet Routes ]
```

1. **Spatial Graph Neural Network (GNN) Encoder (`gnn_encoder.py`)**  
   Encodes latitude, longitude, delivery demand volumes, and time windows into 64-dimensional latent node representations using Graph Attention Networks (GAT) and GraphSAGE convolutions.
2. **Actor-Critic Deep RL Policy (`drl_policy.py`)**  
   Evaluates candidate graph hops in real-time. Action masking dynamically enforces vehicle payload capacities and traffic disruptions.
3. **Neuro-Symbolic 2-Opt Refinement (`drl_policy.py`)**  
   Applies a fast local edge-exchange search to untangle path crossovers generated by neural greedy decoding, guaranteeing provably shorter distances.

Waynex features a transparent, live dual-benchmark engine (`mcp_server.py`) that evaluates routing performance side-by-side against **Google OR-Tools** across 5 core telematics KPIs:

- 📏 **Total Distance Travelled (km)**
- ⏱️ **Max Shift Duration / Makespan (min)**
- 📦 **Vehicle Capacity Utilization (%)**
- ⛽ **Total Fuel Consumed (gal)**
